Browser extension

Dividend research,
inside the quote.

Adds dividend safety, growth streak, last day to buy, pay date and payout ratio to Yahoo Finance quote statistics. Existing Yahoo metrics are skipped. Unavailable API fields do not add empty rows. Free research includes real change-event charts and income calculations. Optional SmarterDividends Pro adds recorded payment history, safety factors, CSV and historical reinvestment comparisons after a secure account connection.

A toolbar lookup also shows the latest distribution increases and decreases. Free research needs no account. Public data is cached locally for six hours; paid research is not disk-cached.

The Chrome Web Store release and public source repository are being prepared. This page will link the approved listing when available.

The extension sends ticker lookups to our free API. There is no analytics, advertising or sale of data. Network requests expose the requesting IP to our server for delivery, security and rate limiting.
