API quickstart

A ticker in.
Dividend facts out.

No API key or account. CORS is enabled. Limit requests to 60 per minute per IP and cache responses.

Try a stock

curl --fail 'https://smarterdividends.com/api/v1/stocks/KO'

Python

import requests
r = requests.get("https://smarterdividends.com/api/v1/stocks/KO", timeout=20)
r.raise_for_status()
print(r.json()["dividend"])

JavaScript

const r = await fetch("https://smarterdividends.com/api/v1/stocks/KO");
if (!r.ok) throw new Error(`API returned ${r.status}`);
console.log((await r.json()).dividend);

Google Sheets

=IMPORTDATA("https://smarterdividends.com/api/v1/stocks/KO?format=csv")

Other endpoints

GET /api/v1/ex-dividend/2026-12-01
GET /api/v1/dividend-changes?week=2026-11-09

The ex-dividend response includes last_day_to_buy using the market holiday calendar. Without week, dividend-changes returns the latest seven days.

Read the fields correctly

FieldMeaning
dividend.forward_yieldIndicated yield as a fraction: 0.03 means 3%.
dividend.annual_amountIndicated annual dividend per share, USD.
dividend.next_ex_date / next_pay_dateISO dates; null means unavailable, not a predicted date.
dividend.payout_ratioFraction; may be null, especially for funds.
dividend.growth_streak_yearsRecorded consecutive years of dividend growth.
safety.grade / scoreModel grade and score; not a guarantee.
changes[].pct_changeFractional change from the preceding classified payment.
as_ofDate of the underlying snapshot.
